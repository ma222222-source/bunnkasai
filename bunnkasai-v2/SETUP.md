# 黒工文化祭 校内マップ v2 セットアップ手順

所要時間：15〜20分。**上から順にやれば動きます。**

---

## 0. 先に知っておくこと（重要）

旧版は **管理者パスワードがHTMLに直書き** されていて、ソースを見れば誰でも係員画面に入れました。
さらに GAS 側が無認証だったため、URL を知っていれば **来場者が混雑状況を書き換えられる** 状態でした。

v2 ではパスワードを **GAS のスクリプトプロパティ** に移し、書き込み時に毎回サーバー側で照合します。
そのため **GAS の入れ替え（手順2）を必ず行ってください。** これをやらないと係員画面が使えません。

---

## 1. スプレッドシートの列を揃える

シート名を **`ブース`** にして、1行目を次のとおりにします（`id` `name` `status` `time` は旧版と同じ。後半4列が新規）。

| A: id | B: name | C: status | D: time | E: category | F: floor | G: note |
|---|---|---|---|---|---|---|
| 1 | 電子科 | 空いています | (自動) | 展示 | 1 | ロボット実演 11:00〜 |
| 2 | 電気科 | 空いています | (自動) | 展示 | 1 | |
| 3 | 機械科 | 空いています | (自動) | 展示 | 1 | |
| 4 | 受付・本部・M科 | 空いています | (自動) | 受付 | 1 | パンフ配布中 |
| 5 | 土木/建築 | 空いています | (自動) | 展示 | 1 | |
| 6 | 商業/工経 | 空いています | (自動) | 展示 | 1 | |
| 7 | 実習棟群 | 空いています | (自動) | 食べ物 | 1 | |
| 8 | 体育館イベント | 空いています | (自動) | イベント | 1 | 12:00 ステージ発表 |

- **status に入れてよい値は4種類だけ**：`空いています` / `やや混雑` / `混雑しています` / `準備中`
  （それ以外を書くとアプリ側で「情報なし」表示になります）
- `category` は自由文字列。一覧画面のフィルタが自動生成されます
- `floor` は `1` か `2`。`2` にすると 2F マップに自動配置されます
- `note` は各ブースの一言。「◯時から実演」など時間情報を入れると効果的
- `time` は触らないでください（GASが自動で書き込みます）

---

## 2. GAS を差し替える

1. スプレッドシート → 拡張機能 → Apps Script
2. 既存コードを **全部消して**、`Code.gs` の中身を貼り付け
3. コード冒頭の `setup()` 関数内、`var PASSWORD = '...'` に **係員用パスワード** を入れる
4. エディタ上部の関数選択で `setup` を選んで▶実行（初回は権限承認が出ます → 許可）
5. **実行できたら `setup()` 内のパスワード文字列を消して保存**（コードにパスワードを残さない）
6. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 発行された `/exec` URL をコピー

> ⚠️ **既存のデプロイを「編集」して更新すると URL が変わりません。** URL を変えたくない場合は
> 「デプロイを管理」→ 鉛筆アイコン →「新バージョン」で更新してください。

## 3. index.html の設定を書き換える

`index.html` の上の方、`CONFIG` ブロックだけ触ればOKです。

```js
const CONFIG = {
  GAS_URL: 'ここに手順2でコピーした /exec URL',
  ...
  ROUTES: {
    denshi: ['4','1','7'],   // ← おすすめコースを回る順の id で指定
    all:    ['4','1','2','3','5','6','7','8'],
    food:   ['8','7','4']
  },
  INFO: {
    timetable: [ ['09:30','開場・受付開始'], ... ],   // ← 実際の予定に
    help:      [ ['🏥','救護室','第1校舎1F 保健室'], ... ]
  }
};
```

校舎の配置を実際に合わせたい場合は、その下の `FLOOR_PLAN` の座標（viewBox `0 0 400 500`）を調整します。
`rooms` の `id` はスプレッドシートの `id` と対応しています。

## 6. LINE公式アカウントと繋ぐ（次のステップ）

### 6-1. リッチメニュー（今すぐできる・コード不要）

LINE Official Account Manager → ホーム → リッチメニュー → 作成

ボタンごとに**開きたいタブを直接指定できます**（`?tab=` パラメータ対応済み）。

| ボタン | アクション | 設定値 |
|---|---|---|
| 校内マップ | リンク | `https://ma222222-source.github.io/bunnkasai/?tab=map` |
| いま空いてる所 | リンク | `https://ma222222-source.github.io/bunnkasai/?tab=list` |
| スタンプラリー | リンク | `https://ma222222-source.github.io/bunnkasai/?tab=stamp` |
| タイムテーブル・困ったときは | リンク | `https://ma222222-source.github.io/bunnkasai/?tab=info` |

特定ブースを開かせたい場合は `?booth=1`（スプレッドシートの id）も使えます。

表示期間を文化祭当日に設定し、「デフォルト表示」をONにします。

### 6-2. LIFF化（やるならこの順で）

1. [LINE Developers](https://developers.line.biz/) でプロバイダー作成 → LINEログインチャネル作成
2. LIFF タブ → 追加
   - サイズ：**Full**
   - エンドポイントURL：`https://ma222222-source.github.io/bunnkasai/`
   - Scope：`profile`（スタンプラリーをアカウント単位で保持したい場合のみ）
3. `index.html` の `CONFIG.LIFF_ID` に発行された LIFF ID（`1234567890-abcdEFGH` 形式）を貼る
   → SDK読み込みと初期化は実装済み。**空のままなら通常のWebサイトとして動作**するので、
     設定しなくても壊れません
4. 発行された LIFF URL（`https://liff.line.me/xxxxx-xxxxx`）をリッチメニューのリンク先に差し替え

> LIFF化のメリットは「LINEアプリから出ずに開ける」こと。
> ブラウザで開くだけでも機能は全て動くので、**当日までに時間がなければ 6-1 だけで十分です。**

## 変更点まとめ（旧版 → v2）

| 項目 | 旧版 | v2 |
|---|---|---|
| 管理者認証 | HTMLに平文 → 実質無防備 | GAS側で照合・クライアントに残さない |
| 書き込み権限 | 誰でもPOST可能 | パスワード必須 |
| 混雑グラフ | ID分岐のダミー | 履歴シートの実データ |
| 一括リセット | ブース数だけ直列POST（約20秒） | サーバー側1リクエスト |
| 負荷対策 | なし | GET を8秒キャッシュ＋同時更新ロック |
| ポーリング | 45秒固定・裏でも動く | 20秒＋非表示時は停止＋失敗時バックオフ |
| 外部依存 | Tailwind CDN（約100KB） | なし（自前CSS） |
| オフライン | 白画面 | Service Workerでシェル保持＋最終取得を表示 |
| 色覚配慮 | 色のみ | 色＋パターン＋アイコン＋文言 |
| 画面構成 | 縦1本 | マップ / 一覧 / スタンプ / インフォ |
| 2F | ダミー矩形1枚 | 実フロアプラン＋`floor`列で自動配置 |
| 係員UI | 全ブース一覧のみ | 担当絞り込み・楽観的更新・未更新警告 |
